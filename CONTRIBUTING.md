# Contributing to ChatApp

Thanks for taking the time to contribute! :tada::+1:

ChatApp is a fork of [Chatwoot](https://github.com/chatwoot/chatwoot), maintained by [H453G4W4](https://github.com/H453G4W4). Since the codebase, tooling, and conventions are inherited from Chatwoot, its [Contributing Guide](https://www.chatwoot.com/docs/contributing-guide) is a good starting point for setup instructions and coding standards.

For ChatApp-specific contributions, please open issues and pull requests on the [ChatApp repository](https://github.com/H453G4W4/chatapp).
